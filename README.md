# Ember

Project site for **Ember**, a solar-powered local AI proposed for the KNOWCASE street
window at Fundación Cotec's Madrid headquarters, submitted to the KNOWCASE Open Call
2027 (Sónar+D × Fundación Cotec).

The site lives in `site/` and is published to GitHub Pages by
`.github/workflows/pages.yml` on every push to `main`.

This repository contains the public project page only. Budget, supplier pricing, and
the technical dossier are deliberately not published here.

Ember uses they/them.
